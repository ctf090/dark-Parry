# Dark Parry

Mod Fabric para Minecraft com combate estilo Dark Souls.

> **Beta:** o mod ainda está em desenvolvimento. Pode ter bugs e mudar bastante.

## O que tem

- **Avanço (R):** dá um impulso em qualquer direção, conforme WASD.
- **Defesa com rebate:** botão direito para defender e rebater ataques.
- **Troca vida/fome:** Shift troca vida por fome, Espaço troca fome por vida.
- **Stamina Apple:** item que devolve estamina. Receita: 4 maçãs + 1 lápis-lazúli (rende 4). Também aparece em baús de masmorra.
- **Zumbis mais fortes:** podem nascer com armadura e jogar poção de veneno.

## Requisitos

- Minecraft 26.3
- Fabric Loader 0.20.1 ou mais novo
- Fabric API
- Java 21 ou mais novo

## Compilar
Rode: ./gradlew build

O `.jar` fica em `build/libs/`.
